# Feeltr

Плёночный фотодневник для мобильных устройств в формате PWA: **https://feeltr.brainsome.app**

## Возможности

- **Плёночные рецепты** (`js/recipes.js`) записаны настройками Fujifilm — симуляция, DR, Highlight/Shadow,
  Color, Color Chrome Effect / FX Blue, зерно, баланс белого со сдвигом, Clarity, экспокоррекция:
  - **Nostalgic Neg.** — тёплый, янтарные светлые участки, насыщенные тени, лёгкая халация.
  - **Classic Negative** — по рецепту Fuji X Weekly «[Not] My X100V Classic Negative».
  - **Copenhagen Negative** — по рецепту Fuji X Weekly (2026).
  - **Classic Retro** — по рецепту Fuji X Weekly (2026); точных значений в открытых источниках нет,
    подобран по описанию (сильное зерно и Color Chrome, DR400, недодержка).
  - **Agfa Ultra 100 v2** — по рецепту Fuji X Weekly для X-Trans V.
  - **Mono +R** — монохром с красным светофильтром: тёмное небо и зелень, светлая кожа.
- **Мультиэкспозиция (MX)** — два кадра в одном. После первого кадра видоискатель показывает живое
  наложение, поэтому второй сюжет можно скомпоновать заранее. Режимы совмещения:
  «Плёнка» (сложение в линейном свете, как две экспозиции на одном негативе), «Экран» и «Светлее»,
  плюс ползунок баланса I/II. Экспозиции совмещаются до проявки, поэтому фильтр и зерно накладываются один раз.
- Форматы кадра 3:4, 2:3 и 1:1, фронтальная/основная камера, импорт фото из галереи
  (подходит и как одна из экспозиций).
- **Дневник** — кадры сгруппированы по дням, к каждому можно добавить заметку, поделиться или скачать.
  Всё хранится локально на устройстве (IndexedDB), без сервера.
- Работает офлайн (service worker), устанавливается на домашний экран.

## Устройство

Статический сайт без сборки:

| Файл | Назначение |
| --- | --- |
| `index.html`, `css/app.css` | разметка и стили |
| `js/app.js` | камера, интерфейс, дневник |
| `js/renderer.js` | WebGL-шейдер: совмещение экспозиций и плёночные фильтры |
| `js/recipes.js` | плёночные рецепты в настройках Fujifilm |
| `js/db.js` | хранилище IndexedDB |
| `sw.js`, `manifest.webmanifest` | PWA |
| `vercel.json` | заголовки для хостинга на Vercel |

Локальный запуск: `python3 -m http.server 8080` и откройте `http://localhost:8080`
(камера работает только на localhost или по HTTPS).

При каждом деплое увеличивайте `VERSION` в `sw.js`, чтобы клиенты получили новые файлы.
